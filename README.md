# 🌍 World Happiness Report Analysis

## 📌 Project Overview
This project analyzes the World Happiness Report dataset using Python to understand global happiness trends and key factors influencing happiness across countries.

The analysis focuses on data cleaning, exploratory data analysis (EDA), and visualization to derive meaningful insights.

---

## 🎯 Objectives
- Analyze happiness scores across countries
- Identify factors influencing happiness
- Compare regional happiness trends
- Perform exploratory data analysis (EDA)
- Visualize insights for better understanding

---

## 📊 Analysis Highlights
- Country-wise happiness score comparison
- Impact of GDP, health, and social support
- Trend analysis across regions
- Data-driven insights through visualization

---

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

---

## 📂 Project Files
- `world_happiness_report_analysis.ipynb` – Jupyter Notebook with full analysis
